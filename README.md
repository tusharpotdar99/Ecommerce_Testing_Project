E-Commerce Application Testing Project
Project Overview

This project focuses on the Manual and Automation Testing of an E-Commerce web application. The objective of the project is to validate the functionality, usability, performance, and reliability of the application by executing different types of testing on major modules such as Login, Registration, Product Search, Cart, Checkout, and Order Management.

The project includes detailed test scenarios, test cases, bug reporting, and automation scripts to ensure the application works according to business requirements and provides a smooth user experience.
